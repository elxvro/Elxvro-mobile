# Neon Apex 3D — GitHub'dan APK

Bu proje bilgisayar olmadan GitHub Actions ile Android APK üretmek için hazırlanmıştır.

## Kullanım
1. Bu klasörü GitHub'da yeni bir repository'ye yükle.
2. GitHub'da **Actions** sekmesine gir.
3. **Build Neon Apex APK** workflow'unu aç.
4. **Run workflow** ile çalıştır.
5. Workflow tamamlanınca **Artifacts** bölümünden `neon-apex-debug-apk` dosyasını indir.
6. ZIP içinden `app-debug.apk` dosyasını Android telefona yükle.

Oyun mobil dokunmatik kontroller içerir. Three.js CDN'den yüklendiği için oyunun açılışında internet bağlantısı gerekir.
